# porsche-sales-dashboard
Dashboard interativo de análise de vendas da Porsche, desenvolvido com auxílio do ChatGPT a partir de dados tratados no Excel, como projeto prático do curso Reclame Aqui – Dados e IA na Prática, da DIO.

# Porsche Sales Intelligence Dashboard

## Sobre o projeto

O **Porsche Sales Intelligence Dashboard** é um projeto de análise e visualização de dados desenvolvido com o objetivo de transformar dados de vendas da Porsche em informações estratégicas para apoiar a tomada de decisões de negócio.

A partir de uma base de dados de vendas, foi desenvolvido um dashboard interativo com identidade visual inspirada na marca Porsche, permitindo explorar o desempenho comercial, identificar preferências dos clientes e analisar a distribuição das vendas por região.

## Perguntas de negócio

O dashboard foi desenvolvido para responder a três questões principais:

1. **Quais são os modelos Porsche mais vendidos nos últimos três anos?**  
   Identificar os modelos com maior volume de vendas no período analisado, permitindo compreender quais veículos apresentam melhor desempenho comercial.

2. **Qual é o principal método de pagamento utilizado pelos clientes?**  
   Analisar a distribuição das vendas por método de pagamento e identificar a preferência predominante entre os consumidores.

3. **Quais são os modelos mais vendidos por região?**  
   Comparar o desempenho dos modelos nas diferentes regiões geográficas dos Estados Unidos, identificando os veículos mais populares em cada localidade.

## Recursos do dashboard

- Indicadores gerais de desempenho de vendas;
- Ranking dos modelos mais vendidos;
- Gráfico de distribuição dos métodos de pagamento;
- Análise dos modelos líderes por região;
- Filtros interativos por ano, região e método de pagamento.

## Tecnologias utilizadas

- **HTML5:** estrutura do dashboard;
- **CSS3:** estilização e identidade visual;
- **JavaScript:** processamento dos dados e interatividade;
- **Excel:** base de dados utilizada na análise.
- **ChatGPT:** ferramenta de IA utilizada para montar o dashboard em HTML; 

## Fonte de dados

Os dados utilizados no projeto foram disponibilizados em uma planilha Excel (`dadosporche.xlsx`), contendo informações sobre modelos, datas de venda, métodos de pagamento, localização e valores das transações.

## Objetivo do projeto

Demonstrar como a análise de dados pode transformar registros comerciais em informações relevantes para o negócio, facilitando a identificação de padrões de consumo, tendências de vendas e oportunidades estratégicas.
